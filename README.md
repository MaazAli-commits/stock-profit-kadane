\# Stock Profit Analysis using Kadane’s Algorithm



This project analyzes historical stock prices to determine the maximum profit that could be achieved from a single buy–sell transaction.



\## Overview

\- Stock price data is fetched using Python and the `yfinance` library.

\- Daily price differences are computed.

\- The maximum profit interval is calculated using:

&nbsp; - Serial Kadane’s Algorithm

&nbsp; - Parallel Kadane’s Algorithm using OpenMP

\- Execution time is measured to compare performance.
